DEFINITIONS (z_flow = F1–F18)
==================================================

A) Geometry control (compute if geometric data is available)
F1 = Reactor length / reactor diameter (L/D)
F2 = Injector diameter / reactor diameter
F3 = Injector penetration / reactor diameter
F4 = Growth zone distance / reactor diameter
F5 = Growth zone distance / reactor length

B) P–T transport state (must compute if P and T exist; gas table helps for F7/F9/F10)
F6 = Gas number density n = P_total / (k_B * T)
F7 = Mean free path λ = k_B*T / (sqrt(2) * π * d_eff^2 * P_total)
     where d_eff is mixture effective collision diameter (m)
F8 = Diffusivity index proxy = (T^1.75) / P_total  (dimensionless_proxy)
F9 = Kinematic viscosity proxy ν = μ(T) / ρ
F10 = Gas density ρ = (P_total * M_mix) / (R * T)

C) Collision and mass transfer
F11 = Carbon number density n_C = p_C / (k_B * T)  (requires p_C)
F12 = C–NP collision index proxy = n_C * sqrt(T)
F13 = Catalyst delivery mode = "floating" | "supported" | "aerosol" | "unknown"
     Determine from paper.json growth/catalyst mode; if not explicit, infer only if directly stated in paper.md; else "unknown".

D) Enhanced (compute only if flow rate/velocity can be obtained)
F14 = Mean velocity v = Q / A
     Q is volumetric flow rate at process conditions (m^3/s)
     If only sccm at STP is given: convert to mol/s at STP then to Q at (P,T) using ideal gas law.
     A = π*(D_reactor/2)^2
F15 = Reynolds number Re = (ρ * v * D_reactor) / μ(T)
F16 = Peclet number Pe = (v * L_char) / D_eff
     Use L_char = D_reactor (default). If D_eff cannot be computed, set null.
F17 = Residence time τ = L_reactor / v
F18 = Damkohler number proxy Da = τ / t_reaction_proxy
     Define t_reaction_proxy = 1 / (max(F12, tiny)) if F12 available; otherwise null.
     If τ is null or t_reaction_proxy is null -> Da = null.

GAS MIXTURE PROPERTIES (use gas_properties.txt)
==================================================

Gas properties table columns used:
- M_g_mol (g/mol) -> convert to kg/mol
- sigma_A (Å) -> convert to meters: sigma_m = sigma_A * 1e-10
- mu_ref_uPa_s, T_ref_mu_K, Sutherland_C_K -> compute μ(T) via Sutherland:
  μ(T) = μ_ref * (T/T_ref)^(3/2) * (T_ref + C) / (T + C)
  where μ_ref in Pa*s (convert μPa*s to Pa*s by ×1e-6)

Mixture molecular weight:
M_mix = Σ (y_i * M_i)

Mixture collision diameter (simple mixing rule for proxy):
d_eff = Σ (y_i * sigma_i)

Mixture viscosity (simple mixing rule for proxy, acceptable for ML features):
μ_mix(T) = Σ (y_i * μ_i(T))
(Do NOT implement complex Wilke unless explicitly requested.)

If any needed gas is not found in gas_properties.txt, treat its required property as missing:
- If composition uses a gas not in table -> mixture property becomes null.
