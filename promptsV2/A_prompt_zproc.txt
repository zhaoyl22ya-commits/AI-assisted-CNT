DEFINITION OF z_proc (P1–P12)

P1 Temperature T
Definition: growth temperature
Unit: K
Source: paper.json process temperature; otherwise explicit temperature in paper.md
If temperature is given in °C, convert to K using T = T_C + 273.15

P2 Pressure P
Definition: total reactor pressure
Unit: Pa
Source: paper.json; otherwise explicit pressure in paper.md
If pressure is given in atm or torr, convert to Pa

P3 Growth time t
Definition: effective CNT growth or reaction time
Unit: s
Source: paper.json; otherwise explicit duration/time in paper.md
If given in minutes, convert to seconds

P4 Carbon fraction C_total
Definition: total mole fraction of carbon-containing gas(es) in the feed
Unit: mole_fraction
Source: paper.json gas composition; otherwise explicit mole fraction or flow
ratio in paper.md
Do NOT compute from chemistry unless explicitly given
If carbon source is named but no fraction or flow is provided, set null

P5 Hydrogen fraction H2
Definition: mole fraction of hydrogen in the feed gas
Unit: mole_fraction
Source: paper.json gas composition; otherwise explicit fraction or flow in paper.md
If hydrogen presence is stated but no fraction is given, set null

P6 Inert fraction
Definition: total mole fraction of inert carrier gases (e.g., Ar, N2, He)
Unit: mole_fraction
Source: paper.json gas composition; otherwise explicit fraction or flow in paper.md
If inert gas is named without fraction/flow, set null

P7 Carbon source type
Definition: chemical identity of the carbon source
Unit: category
Examples: methane, ethylene, acetylene, CO, ethanol, benzene, mixed
Source: paper.json or explicit statement in paper.md
If multiple carbon sources are explicitly stated, use "mixed"
If not stated, set null

P8 Carbon partial pressure p_C

Definition: partial pressure of carbon-containing gas(es)
Unit: Pa
Computation rule:
p_C = C_total × P
If either C_total or P is null, p_C must be null

P9 Hydrogen partial pressure p_H2
Definition: partial pressure of hydrogen
Unit: Pa
Computation rule:
p_H2 = H2_fraction × P
If either H2_fraction or P is null, p_H2 must be null

P10 p_C / p_H2
Definition: global carbon chemical potential proxy
Unit: dimensionless
Computation rule:
p_C / p_H2
If p_C or p_H2 is null, or p_H2 = 0, set null

P11 Oxidant oxygen-atom fraction O_total
Definition: oxygen-atom-equivalent mole fraction contributed by explicitly stated oxidant/etchant species in the feed.
Unit: mole_fraction
Recognized oxidant/etchant species and oxygen atom counts n_O:

H2O: 1
O2: 2
CO2: 2
CO: 1
O3: 3
NO: 1
NO2: 2
N2O: 1

Extraction rule (STRICT):

Use paper.json gas composition first. If an oxidant species has an explicit mole fraction, use it as x_i.
If only flow values are explicitly given (e.g., sccm for each gas), you may compute x_i = flow_i / total_flow ONLY if all required flows to define total_flow are explicitly provided in the same source.
If paper.md explicitly provides numeric mole fraction, flow, or ppm(ppmv) for an oxidant species, extract it.
If ppm(ppmv) is given, convert to mole fraction by x_i = ppm × 1e-6.
If only qualitative statements exist (e.g., "water-assisted", "oxygen-assisted", "trace oxygen", "ppm-level" without numeric value), set O_total to null.
Do NOT infer oxidant presence from outcomes or typical recipes.
Computation:
O_total = Σ (x_i × n_O(i)) over all recognized oxidant species with known x_i.
If no recognized oxidant species has an explicit numeric x_i, set null.
P12 O_total / C_total
Definition: ratio of oxygen-atom-equivalent mole fraction to carbon-containing gas mole fraction.
Unit: dimensionless
Computation rule:
O_total / C_total
If O_total is null or C_total is null, or C_total = 0, set null
