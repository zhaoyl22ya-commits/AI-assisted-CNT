================================================================
PART 1 — NUMERIC RANGE RULE (MANDATORY)
================================================================
Whenever you encounter a numeric range such as:
 - 700–900 °C
 - 30–120 min
 - 500–1500 sccm
 - 5–15 nm

You MUST:
1. Identify min and max.
2. Compute midpoint = (min + max)/2.
3. Use ONLY the midpoint as the extracted numeric value.
4. Keep the normalized units (see PART 5).

This rule applies to:
- temperature
- pressure (if ranges exist)
- gas flow
- CNT diameter
- CNT length
- catalyst nanoparticle size
- catalyst film thickness
- plasma parameters (power, bias, etc.)
- any other numeric range that appears in CNT growth conditions.

If a range applies to PECVD-specific parameters (plasma power, bias voltage, plasma-substrate distance, etc.) You MUST also take the midpoint.

F5 — PECVD REQUIRED CALCULATIONS
================================================================
ALL CALCULATIONS MUST FOLLOW A-TYPE CALCULATION LOGIC.
NO DEFAULT VALUES ARE ALLOWED EXCEPT atmospheric pressure rule.

----------------------------------
(1) Carbon feed molar flow F_C (mol/s)
----------------------------------
If carbon gas flow, temperature, and pressure exist:

F_C = (flow_C_source_sccm / 60000) * (P / (R * T_K))

Store in:
"calc_block.carbon_feed_mol_s": ""

----------------------------------
(2) Carbon concentration c_C (mol/m³)
----------------------------------
c_total = P / (R * T_K)
c_C = c_total × (flow_C / total_flow)

Store:
"calc_block.carbon_concentration_mol_m3": ""

----------------------------------
(3) Metal concentration c_M (mol/m³)
----------------------------------
Only compute if:
- metal film thickness, density, zone volume, or mol feed is explicitly given.

Store:
"calc_block.metal_concentration_mol_m3": ""

----------------------------------
(4) Carbon-to-metal atomic ratio per second (NEW, modified)
----------------------------------
Instead of total C/M ratio, compute:

C_M_ratio_per_s = (carbon_feed_mol_s) / (metal_atom_mol_on_substrate)

Store:
"calc_block.C_M_ratio_per_s": ""

----------------------------------
(5) Nanoparticle atom count N_atoms_per_NP
----------------------------------
If nanoparticle diameter exists:

1. Compute NP volume (nm³ → m³)
2. Use metal density ONLY if explicitly written in article.
3. Use metal molar mass ONLY if explicitly written.

N_atoms = (ρ × V_NP / M_metal) × N_A

Store:
"calc_block.nanoparticle_atom_count": ""

----------------------------------
(6) Nanoparticle density (per m³)
----------------------------------
If NP density is given → convert to /m³.

Store:
"calc_block.nanoparticle_density_per_m3": ""

----------------------------------
(7) Carbon-to-nanoparticle ratio per second (NEW, modified)
----------------------------------
C_NP_ratio_per_s = (carbon_feed_mol_s) / (nanoparticle_number_on_substrate)

Store:
"calc_block.C_NP_ratio_per_s": ""

----------------------------------
Missing information
----------------------------------
If any value cannot be computed:
- Set ""
- Explain in calc_block.notes AND calc_block.calc_steps.

PART 8 — PECVD CNT GROWTH QUALITY SCORING (MODE F ONLY)
================================================================

After extracting all PECVD CNT growth parameters, the system MUST evaluate
the quality and effectiveness of this plasma-enhanced CNT growth process (Mode F).

You MUST output one integer score (1–10) in the JSON field:

"growth_quality_score_F": ""

inside each synthesis_x block.

SCORING RULES (MANDATORY)

Determine the score strictly from explicit textual descriptions found in the paper.
Do NOT invent values, do NOT assume typical plasma power, bias voltage, or nanotube
dimensions. Evaluate ONLY based on written content.

Assign 0, 0.5, or 1 point for each of the following 10 factors:

1. Plasma stability and effectiveness
   - clear stable plasma, described as uniform or well-sustained = 1
   - partially stable / somewhat noisy plasma = 0.5
   - unstable / poorly described / missing = 0

2. CNT vertical alignment quality (textual)
   - well-aligned vertical array / forest = 1
   - partially aligned bundle-like structure = 0.5
   - random or unclear = 0

3. Catalyst nanoparticle activation under plasma
   - well-defined NP formation, uniform activation = 1
   - partially described / moderate activation = 0.5
   - unclear or absent = 0

4. Plasma-assisted growth rate
   - high growth rate or rapid vertical forest formation reported = 1
   - moderate / qualitative improvement = 0.5
   - not mentioned / unclear = 0

5. Nanotube structural quality
   - high graphitization, sharp Raman G-band, smooth walls = 1
   - moderate quality / some defects = 0.5
   - high defect density / unclear quality = 0

6. Substrate heating and uniformity
   - clearly controlled substrate temperature and uniform heating = 1
   - partially controlled = 0.5
   - not discussed = 0

7. Plasma–substrate interaction conditions
   - distance, bias, ion-energy effects clearly described = 1
   - partially described = 0.5
   - missing = 0

8. Catalyst–plasma compatibility
   - catalyst survives plasma without deactivation, good NP stability = 1
   - moderate stability = 0.5
   - unstable / unclear = 0

9. CNT density, height, or thickness of forest (textual)
   - high-density forest, thick film, or tall array = 1
   - moderate film formation = 0.5
   - sparse / not described = 0

10. Process reproducibility
    - explicitly reproducible (multiple runs, consistent results) = 1
    - implied reproducible = 0.5
    - not mentioned = 0

================================================================
FINAL SCORE RULE
================================================================
FINAL_SCORE = sum(points from 10 categories), then round to nearest integer.

Store results in:

"growth_quality_score_F": ""
"quality_evidence": "Explain which textual descriptions supported each score."
