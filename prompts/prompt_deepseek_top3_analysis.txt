# Background: What this system is
This project is "CNT Growth WorldMap OneClick", a 3-level ML-assisted decision system for CNT growth recipes.

WorldMap metaphor:
- L123 = Administrative zoning of the catalyst-composition/process-package space:
  It defines WHERE CNT growth is feasible and promising at a coarse level (regions / districts).
- L12 = Route planning with uncertainty:
  It predicts q10/q50/q90 quantiles for performance, enabling risk-aware navigation through process space.
  Risk is typically measured by interval width (q90 - q10). Smaller width = higher confidence.
- L1 = Address-level locator (high-resolution refinement):
  It predicts a single best point-estimate score and refines the final ranking to “street address precision”.

IMPORTANT 3.0 REPRESENTATION NOTE:
In the 3.0 system, CNT growth conditions are not represented only by scattered raw process variables.
Instead, the model uses four structured latent-space representations:

- z_nuc  → nucleation-related latent space
- z_C    → catalyst/carbon-related latent space
- z_flow → flow / transport latent space
- z_proc → process-window latent space

In the input tables, these latent spaces are flattened as:
- N1..N18   for z_nuc
- C1..C12   for z_C
- F1..F18   for z_flow
- P1..P12   for z_proc
- miss_*    for missingness indicators

Therefore, you must interpret the TOP-3 candidates from the four-latent-space perspective,
not merely as a traditional raw-parameter table.

The system screens catalysts, proposes top process packages for each catalyst, and provides physical-state targets
(e.g., nanoparticle size window and carbon-to-NP ratio) to guide real experiments.

# What the tables mean (typical columns)
You will receive CSV tables for TOP-3 selected process-package rows, plus related physical-state recommendations.
Interpret them as follows:

Primary 3.0 package-level rows:
- Each TOP-3 row is a selected process-package candidate.
- `template_id` identifies the route/process template.
- `final_score` is the final refined ranking score (higher is better).
- `score_balanced`, `score_robust`, `score_potential` are three risk-preference views.
- `pred_L1` is the L1 point-estimate prediction.
- `pred_q10/q50/q90` are L12 quantile predictions.
- `risk_q90_q10` is uncertainty width; smaller means more reliable.

Latent-space variables:
- `N1..N18` describe the nucleation regime (`z_nuc`).
- `C1..C12` describe the catalyst/carbon regime (`z_C`).
- `F1..F18` describe the transport/flow regime (`z_flow`).
- `P1..P12` describe the process-window regime (`z_proc`).
- `miss_*` columns indicate missingness and should be interpreted as uncertainty/context flags, not direct physical targets.

Human-readable catalyst labels:
- `metal1/metal2/metal3` and `frac1/frac2/frac3` are explicit catalyst composition labels for readability.
- A string like "Co:0.33;Cu:0.33;Fe:0.34" may appear in catalyst_id or recipe_key.
- These labels are useful, but the latent-space variables remain the primary ML representation.

Physical-state targets:
- Physical-state recommendation tables may contain `recommended_np_size_nm`, `recommended_log_C_NP_ratio`,
  or related nanoparticle / carbon-to-particle state descriptors.
- Treat these as actionable tuning targets for experiments.

Interpretation rule:
- Do not treat the candidate only as a conventional recipe row.
- First infer what kind of growth regime the candidate represents in z_nuc / z_C / z_flow / z_proc.
- Then translate that latent-space pattern into practical experimental controls.

# Your mission
Only analyze the TOP-3 selected process-package candidates in the input. For each candidate, do ALL of the following:

1) Latent-space interpretation (core 3.0 view)
- Explain what the candidate means in the four latent spaces:
  - z_nuc  (N1..N18): what nucleation / nanoparticle formation regime it implies
  - z_C    (C1..C12): what catalyst/carbon supply regime it implies
  - z_flow (F1..F18): what transport / flow regime it implies
  - z_proc (P1..P12): what process-window regime it implies
- If some latent dimensions are hard to interpret individually, explain them through the overall regime they suggest.

2) Score interpretation (model view)
- Explain why it ranks high/low using final_score and (if present) pred_q10/q50/q90/risk_q90_q10.
- Explain whether it looks robust (low uncertainty) or exploratory (high uncertainty).
- If q50 is not between q10 and q90, treat it as a model artifact and recommend a local sweep to de-risk.

3) Practical process-package guidance (lab-ready)
- Choose the best starting package(s) from the provided tables.
- Translate the latent-space recommendation into a step-by-step execution plan:
  (a) what to set first (T, pressure, time, gas composition, precursor feeding strategy),
  (b) what to tune second (carbon fraction vs H2 vs total flow / residence time),
  (c) safe windows and “do not cross” boundaries.
- If the system is missing a parameter (e.g., precursor type), state assumptions and provide options.

4) Physical-state targeting strategy (physics view)
- Translate the recommended NP size / carbon-to-particle targets into actionable controls:
  precursor concentration, residence time, flow rate, temperature, H2 role (etching), and deposition behavior.
- Explain what to measure: SEM/TEM NP size distribution, CNT density, Raman G/D, yield, alignment, etc.
- Provide a feedback loop:
  “If NP too large → do X; if amorphous carbon → do Y; if CNT density too low → do Z”.

5) Risk and de-risk plan
- If risk is small: explain why it is safe and what might still go wrong.
- If risk is large: propose a minimal DoE sweep around the recommended point:
  e.g., T ± 20°C, carbon fraction ± 20%, H2 fraction ± 10%, flow/residence-time adjustment,
  and explain what outcomes to watch.

6) SOP checklist + troubleshooting
- Provide a short checklist for pre-run, during run, post-run.
- Provide a troubleshooting table:
  “symptom → likely cause → adjustment”.

7) Final recommended priority order
- Give a ranked experiment plan: which candidate and which process package to try first/second/third and why.

# Output format requirements
