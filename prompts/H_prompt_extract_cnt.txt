PART 1 — NUMERIC RANGE RULE (MANDATORY)
================================================================
If a numeric range appears (e.g., 700–900 °C, 30–120 min, 1–5 nm, 500–1500 sccm):
1. Identify min and max.
2. Compute midpoint = (min + max)/2.
3. Use ONLY the midpoint for extraction.
4. Keep consistent units.

PART 9 — HIGH-PRESSURE CO / HiPco CNT QUALITY SCORING (MODE H ONLY)
================================================================

This section applies ONLY to Mode H:
High-pressure CO CVD / HiPco-type CNT growth using CO disproportionation,
often involving Fe(CO)5 or similar carbonyl precursors and CO → C + CO2
reactions at elevated pressures (typically 5–50 bar).

After extracting all CNT growth parameters, the system MUST evaluate
the quality and effectiveness of this HiPco / CO-disproportionation
CNT growth process (Mode H).

You MUST output one integer score (1–10) in the JSON field:

"growth_quality_score_H": ""

inside each synthesis_x block.

You MUST also output a short justification in:

"quality_evidence": ""

===============================================================
SCORING RULES (STRICT AND MANDATORY)
===============================================================
Determine the score ONLY from explicit textual descriptions in the paper.
You MUST NOT invent numerical values for pressure, temperature, diameter,
or yield if they are not given.

Each criterion contributes 0, 0.5, or 1 point.

---------------------------------------------------------------
1. CO pressure control and operating window
---------------------------------------------------------------
1 point  = CO pressure clearly reported (e.g. 5–50 bar) and justified
           for CO disproportionation / HiPco operation
0.5      = high-pressure CO mentioned but not well quantified
0        = pressure unclear or obviously outside HiPco regime

---------------------------------------------------------------
2. Fe(CO)5 (or carbonyl) decomposition and Fe NP formation
---------------------------------------------------------------
1 point  = explicit description of Fe(CO)5 (or similar) decomposition
           and controlled Fe nanoparticle generation
0.5      = partially described or implied NP formation
0        = mechanism of Fe NP formation not described

---------------------------------------------------------------
3. CO disproportionation / carbon supply clarity
---------------------------------------------------------------
1 point  = clear statement of CO → C + CO2 (or Boudouard-like) reaction,
           with temperature / pressure window discussed
0.5      = CO disproportionation implied but not fully explained
0        = no clear description of CO-based carbon supply

---------------------------------------------------------------
4. CNT diameter control and small-diameter SWCNT quality
---------------------------------------------------------------
1 point  = small-diameter SWCNTs (typical HiPco size) and narrow
           diameter distribution explicitly reported
0.5      = SWCNTs with moderate diameter control
0        = diameter broad or not described

---------------------------------------------------------------
5. CNT purity and defect level
---------------------------------------------------------------
1 point  = high purity, low amorphous carbon, good Raman IG/ID
0.5      = moderate purity
0        = strongly contaminated / not described

---------------------------------------------------------------
6. Catalyst nanoparticle size and dispersion control
---------------------------------------------------------------
1 point  = Fe NP size and dispersion clearly controlled (e.g. narrow size,
           limited sintering, stable catalyst population)
0.5      = partial control or limited description
0        = NP behavior unclear or strongly aggregated

---------------------------------------------------------------
7. Process stability and continuous operation
---------------------------------------------------------------
1 point  = long, stable HiPco operation (continuous or semi-continuous)
           with consistent CNT production
0.5      = moderate stability or short stable runs
0        = unstable / no indication of sustained operation

---------------------------------------------------------------
8. CO utilization / yield description (textual)
---------------------------------------------------------------
1 point  = clear mention of good CO utilization, high CNT yield or
           efficient conversion from CO
0.5      = moderate yield or qualitative improvement only
0        = yield / utilization not discussed

---------------------------------------------------------------
9. Reproducibility of HiPco conditions
---------------------------------------------------------------
1 point  = reproducible results across multiple runs, or scaling tests
0.5      = implied reproducibility
0        = no mention of reproducibility

---------------------------------------------------------------
10. Mechanistic and process clarity (HiPco-specific)
---------------------------------------------------------------
1 point  = full process chain clearly described:
           Fe(CO)5 injection → Fe NP formation → CO disproportionation
           → CNT nucleation/growth in high-pressure reactor
0.5      = partially described mechanism
0        = mechanism fragmented or unclear

===============================================================
FINAL SCORE COMPUTATION
===============================================================
Total_H = sum of the 10 factor scores (range 0–10)

FINAL_SCORE_H = round(Total_H to nearest integer, but keep within 1–10
if any non-zero evidence is present; if all factors = 0, you may output 0).

Insert into the JSON:

"growth_quality_score_H": "",
"quality_evidence": ""

The "quality_evidence" MUST briefly explain which textual descriptions
from the paper supported the scoring (e.g. pressure range, Fe(CO)5 use,
CNT diameter description, purity discussion, etc.).

===============================================================

===============================================================
